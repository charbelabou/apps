# Fonts

The fonts the apps themselves use, hosted here so the page makes no third-party requests. The files are the original,
unmodified fonts, only re-packaged as WOFF2. Each is under the SIL Open Font License 1.1; the licence text and
copyright line for each is in `licenses/`.

| File | Font | Used for |
|---|---|---|
| `BowlbyOne_400Regular.woff2` | Bowlby One | Kezbe Bayda title and buttons |
| `TitanOne-Regular.woff2` | Titan One | Massela title and buttons |
| `DMSans_500Medium.woff2`, `DMSans_700Bold.woff2` | DM Sans | Everything else |
