# Fonts

DM Sans, the body font of Kezbe Bayda, hosted here so the page makes no third-party requests. The files are the original,
unmodified font, only re-packaged as WOFF2. It is under the SIL Open Font License 1.1; the licence text and copyright
line are in `licenses/`.

| File | Used for |
|---|---|
| `DMSans_500Medium.woff2` | Body text |
| `DMSans_700Bold.woff2` | Titles and buttons |
