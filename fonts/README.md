# Fonts

Self-hosted so the page makes no third-party requests. All five files are the original, unmodified fonts, only
re-packaged as WOFF2. Each is under the SIL Open Font License 1.1; the licence text and copyright line for each
is in `licenses/`.

| File | Font | Used for |
|---|---|---|
| `BowlbyOne_400Regular.woff2` | Bowlby One | Kezbe Bayda headings and buttons |
| `Rubik_700Bold.woff2` | Rubik Bold | The Kezbe Bayda question text |
| `TitanOne-Regular.woff2` | Titan One | Massela headings and the word card |
| `DMSans_500Medium.woff2`, `DMSans_700Bold.woff2` | DM Sans | Body text |
